# Security and Responsible Use

NADI is research software. Its outputs must not replace certified laboratory
testing, public-health guidance, utility operating procedures or regulatory
requirements.

Do not connect the software to automatic valve, dosing or public-warning actions
without independent engineering review, fail-safe design, authorisation and
prospective validation.

Please report security issues privately to the repository owner rather than
opening a public issue containing exploit details or sensitive infrastructure
information.
