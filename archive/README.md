# Historical NADI artifacts

Historical V1–V5 simulations, protocol deviations, prior reports and delivery ZIPs remain at their original paths until a hash-checked migration is completed. `reports/migration_manifest.csv` records proposed destinations and current move status. An archive label never changes a simulated result into observed biological evidence.

`historical_index.csv` is the non-destructive reviewer index generated from
the Phase 0 classification. It records each historical/superseded/generated
artifact's original location, role, evidence track and current retention
status. It is an index, not a duplicate evidence store.
