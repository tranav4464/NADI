# Adoption Boundary

NADI is currently a research decision-support prototype. A bounded utility
pilot would require a pseudonymised local network graph, actual operating and
valve states, calibrated pressure/flow/chlorine telemetry, independent
microbiology with timestamps and quality control, and a human response owner.

The software may rank confirmatory sampling locations and expose uncertainty.
It must not autonomously issue public-health declarations, close supply, or
replace certified laboratory testing. Utility operators retain override
authority. Infrastructure data must be access-controlled, household identifiers
excluded, model versions logged, and every alert auditable.

The first pilot claim should be narrow: under a fixed sampling budget, does the
prospective ranked list find independently confirmed affected locations sooner
or with fewer tests than routine sampling? Only after that evaluation could
field-performance or exposure-reduction claims be considered.
