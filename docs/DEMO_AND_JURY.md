# Demonstration and Jury Defence

## Three-minute live demonstration

1. Open the dashboard and state that the event and network truth are simulated.
2. Show the calibrated risk interval and support score, not only a point score.
3. Show the 24-scenario affected-region probabilities and arrival interval.
4. Run budget three. Explain that each hidden result is revealed only after selection.
5. Show the ordered test list, worst-case regret, certificate and adversarial scenario.
6. Change the requested domain to Delhi. NADI must abstain because local calibration is absent.
7. Open the V3 evidence chart and state both results: equivalence passed; superiority did not.

## Questions the mathematics must survive

**Why not rank risk scores?** A risk score does not include reach uncertainty,
consequence, limited test budget or the information gained from the first test.

**What does the certificate mean?** Relative to the declared finite risk and
hydraulic scenario set, no compatible scenario makes the selected policy more
than epsilon worse than its scenario-specific oracle. It is not a regulatory
or universal safety certificate.

**Why minimax regret rather than worst loss?** Regret measures avoidable loss
relative to what could have been done in the same scenario, reducing the
tendency of pure minimax rules to choose universally defensive actions.

**Does pressure/turbidity detect E. coli?** No. NADI estimates contextual risk;
an accepted microbiological test is required for confirmation.

**Is this Delhi?** No. Net3 is a public benchmark. The Delhi request is included
as a deliberate abstention test.

**Did SDAIF win the benchmark?** It matched the strongest fair adaptive
comparator. It did not demonstrate superiority. Its added outputs are robust
regret certification, adversarial explanation and explicit abstention.
